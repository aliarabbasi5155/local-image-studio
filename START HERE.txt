YOUR LOCAL IMAGE STUDIO

THE PHONE-FRIENDLY WEBSITE
1. Open Docker Desktop and wait until it is running.
2. Double-click "Start Web Studio.command" in this folder.
3. Open the address it prints and enter your six-digit PIN.
4. For your phone, use the "On your phone" address on the same Wi-Fi.

Create = type a description, choose quality, size and variations, then Create image.
Each generated image starts a project. Upload image saves a photo as a new project
and opens its editor. You can close it without doing an edit; the original stays.
Minimize folds the main Create panel away. Expand brings your draft back.

Open a project to see Image 0, its generated or uploaded original.
The thumbnails below show all its edits in time order. Tap one to select it.
Type in the box below the photo to edit that selected image. Each variation becomes
another child in the same project. The prompt that made the image is shown too.
Compare with Immediate parent or Original (Image 0), then move the divider/slider.
Deleted parents stay available as comparison sources; their thumbnail disappears.
Use the previous/next arrows at the top to switch projects.
Pinch the photo to zoom, or use the +/- and 100% buttons. Drag to pan while zoomed.
Fullscreen uses the whole screen when the browser supports it. Hide controls,
or tap the photo/background, for an uncluttered view; tap again to show controls.
Escape returns from browser fullscreen. H toggles controls. Left/right move
between versions; Shift + left/right move between projects when the photo is focused.

Edit settings contains Quality, Output size, Resize, Variations, Seed and SNOFS.
Match original keeps the exact photo dimensions with Resize / AI upscale.
2K / 4K = 2048 / 4096 pixels on the longest edge. Edits keep the photo's shape.
No resize - native size saves the smaller model output directly. No resize -
full size generates directly at the selected size, in 16-pixel steps; it takes
longer and uses more memory. Choices and prompts stay saved in each image recipe.

The menu beside the project arrows lets you favorite the selected image,
reuse settings, download its recipe, archive the project or delete it.
Delete this image removes only that version. Its descendants are kept.
Delete whole project removes its original and all edits after confirmation.
The down arrow on a library thumbnail downloads the original as PNG or JPG.
Downloads below the selected image save that version. JPG is easy to share;
PNG keeps generation settings. Uploaded originals have no generation recipe.

Estimated times are approximate ranges, learned from completed runs on your Mac.
Queued images show estimated time remaining, including the studio queue.
Tap the server status above the library for memory, recent image times, queue,
engine response and free image storage. These readings refresh automatically.
Start with Fast quality while exploring. All results save automatically.
Keep your Mac awake and Docker Desktop running while generating.
Your PIN and library stay in studio-data. Full guide: studio/README.md.

THE COMFYUI WORKFLOWS

Opening it again
1. Double-click "Start Image Studio.command" in this folder.
2. Wait for the browser to open ComfyUI.
3. Click Workflows on the left (the connected-circles icon).
4. Choose "01 - Create Images" or "02 - Edit Images".

The workflows are saved on your Mac. You can close the launcher Terminal
window after it says Ready. Closing the browser also keeps the studio running.
After restarting your Mac, just double-click the launcher again.

01 - CREATE IMAGES
Type a description in the middle box. Click the blue Run button at the top
right once. Wait for the result on the right.

Example: A photograph of a small Italian cafe at sunrise, warm light,
terracotta walls, realistic details.

02 - EDIT IMAGES
Click "choose file to upload" in the Load Image box on the left and select
your photo. In the middle box, describe what should change. Click Run once.
An example photo is already selected so you can practice immediately.

Example: Change the coat to red. Keep the same face, scarf and background.

Your original photo stays unchanged. AI edits can also change other details;
check the result and try a clearer instruction if needed.

SETTINGS TO START WITH
Keep steps at 4 and guidance at 1.0.
Create Images starts at 1024 x 1024; Edit Images starts at 768 x 768.
Larger images take longer. Expect a few minutes; editing can take longer.
"randomize" makes a fresh variation each run. "fixed" keeps the seed.
The red X beside Run stops the current generation.

FINDING YOUR IMAGES
Open this project's outputs folder:
  create-images = new images
  edit-images   = edited images
Every result is saved automatically as a PNG.

KEEPING A RECIPE
To keep a particular prompt or edit, use the workflow menu's Save As option
and give your copy a new name. Keep the two starter workflows as templates.
Generated PNG files also contain their workflow: drag a result PNG onto the
ComfyUI canvas to restore the recipe that produced it.

MOVING AROUND
Scroll on the empty canvas to zoom. Click an empty part of the canvas, then
the Fit View button at the bottom to see the whole workflow. You do not need
to add nodes or reconnect any wires.

IF SOMETHING GOES WRONG
If the browser cannot connect, double-click Start Image Studio.command again.
If you see a red error, copy its text so it can be checked.
Startup details are in runtime/comfyui-launcher.log.
