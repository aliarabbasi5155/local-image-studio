Send a photo to your studio

Keep your Mac awake and connect your phone to the same home Wi-Fi.

Android

  1. Open the secure studio in Chrome and install it using ⋮ → Install app. Open the installed app once to update it.
  2. In Photos, Gallery or Files, select a photo and tap Share → Image Studio.
  3. Unlock the studio if asked, then tap Import photos. The original is saved in your library and opens ready to edit.

You can send up to 10 PNG, JPEG or WebP photos, up to 20 MB each and 100 MB total. Pending photos stay on the phone for up to 24 hours, including while offline. Import or discard them from the shared-photo notice. If Image Studio does not appear in Share after updating, reinstall the app from the same secure address; your library stays on the Mac.

iPhone / iPad

iOS does not let installed web apps receive photos directly from Share. Create a Shortcut named Send to Image Studio once, then use it from the Photos share sheet.

First complete the studio’s certificate setup and open its HTTPS address on this phone. Shortcuts also needs permission to access the Mac on your local network.

  1. In Shortcuts, create a shortcut named Send to Image Studio. In its Details, enable Show in Share Sheet, accept only Images, and set no input to Stop and Respond.
  2. Add Get Item from List: get First Item from Shortcut Input. This shortcut sends one photo at a time.
  3. Add Resize Image using that item: width 2048, height Auto. Add Convert Image: convert the resized image to JPEG. This also handles iPhone HEIC photos.
  4. Add a URL action with the upload address above.
  5. Add Get Contents of URL. Expand its options: method POST; add a header named X-Studio-PIN whose value is your studio PIN (keep any leading zero). Set Request Body → File and select the Converted Image variable from the Convert Image action. Do not use the URL as the file.
  6. Add Get Dictionary Value: get url from the result of Get Contents of URL.
  7. Add If that value has any value: Open URLs with that value. In Otherwise, get error from the Get Contents of URL result and use Show Alert to display it.

Now select one photo in Photos and choose Share → Send to Image Studio. Allow local network access if asked. The photo is uploaded immediately using your PIN, then its project opens in the browser. Safari may ask you to unlock the studio separately. The same photo is also available in your installed app’s library.

The PIN stays in your private Shortcut; do not share a configured copy. If you change your PIN or Mac address, update the Shortcut. A failed connection leaves the original in Photos; run the Shortcut again when your Mac is reachable. Very large panoramas may need a smaller resize to stay under 16 megapixels.
