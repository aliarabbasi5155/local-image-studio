A few useful basics

Each library card is a project. Create an image or upload a photo to start one. Open it, choose a thumbnail, and use the edit box to make a child of that image. Uploads stay saved even without an edit.

Turn Compare on or off and choose the parent or original. Pinch to zoom. Tap the center to fade controls in or out; tap an edge to move between images. A project marker shows when the next tap crosses into another project.

Fast is a quick starting point. Balanced and High use the more detailed model. With Preset output, High also generates more pixels.

With Resize / AI upscale, Match original keeps an edit’s exact photo dimensions. 2K and 4K use 2048 or 4096 pixels on the longest edge. Edits keep your photo’s shape; the final size appears below the controls.

Choose No resize · native size to save the model output without enlargement. Choose No resize · full size to generate directly at the selected size; larger images take longer and use more memory. No-resize dimensions use 16-pixel steps. Your choice is saved with each image.

Favorites shows individual starred images. A project heart indicates that it contains favorites. Select projects or images for bulk favorites, PNG/JPG ZIP downloads or deletion. Archive hides a whole project until you restore it. Deletion asks for confirmation.

Open any image to reuse its settings, copy its prompt or recipe, edit it, or download PNG/JPG. Edits create a new image and keep the original. Progress percentages count actual engine steps; timing learns from similar completed runs.
